# TiendaPrimero-Assets

Imágenes de marca del proyecto **Tienda Primero** que necesitan ser
alcanzables públicamente para renderizarse en correos automatizados
(informes de visita) y en los PDF que se generan a partir de ellos.

## Regla de uso

Este repositorio es **público**. Sube aquí únicamente logotipos e
imágenes de marca. No subas datos de tiendas, resultados de checklist,
definiciones de KPI, listados de personas ni ningún documento interno:
lo que entra a un repositorio público queda en el historial de Git
aunque después se borre.

Todo lo demás del proyecto vive en SharePoint:
`BIfiles > RETAIL > Tienda Primero`
